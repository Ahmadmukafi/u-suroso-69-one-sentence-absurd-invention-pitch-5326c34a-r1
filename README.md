Entry for the make.fun competition "One-Sentence Absurd Invention Pitch".

## The pitch

> A doormat that sighs loudly every time someone wipes muddy shoes on it, so guests learn manners through guilt instead of reminders.

One sentence, 131 characters. The annoyance is muddy shoes on the doormat; the
invention is a doormat with feelings; the silly-but-plausible mechanism is
manners taught through guilt instead of reminders. The laugh comes from the
invention itself, not from a joke bolted on at the end.

## How it works

`main.ts` writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Run it with `node main.ts`.
